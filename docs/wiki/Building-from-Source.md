# Building from Source

Requirements: Rust (stable), Node.js and pnpm (version from `packageManager`
in `package.json`), and the Tauri system libraries – on Arch `webkit2gtk-4.1`,
`gtk3`, `libayatana-appindicator`, `alsa-lib`, `librsvg`.

```bash
git clone https://github.com/Elementary-Beginnings/ps2-tracker.git
cd ps2-tracker
pnpm install
pnpm tauri dev                      # app with hot reload
pnpm tauri build                    # release build
```

Arch package from the repository: `cd packaging/arch && makepkg -si`.

## Checks

```bash
pnpm build && cargo test --workspace
pnpm check && pnpm test
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
node tools/contrast.mjs              # WCAG 2.1 AA contrast of the accent colours
python3 -I tools/check_links.py .    # links in all Markdown files, also the wiki
PS2_SERVICE_ID=<id> cargo run -p ps2-tracker-core --example census_probe -- <character>
PS2_SERVICE_ID=<id> cargo run -p ps2-tracker-core --example ess_probe -- 10 20
```

`gitleaks` runs as a pre-commit hook: `git config core.hooksPath .githooks`.

## Build-time defaults

Builds from source contain no project IDs. Official builds set them from GitHub
Actions secrets and variables:

| Variable (compile time) | Purpose |
|---|---|
| `PS2_DEFAULT_SERVICE_ID` | built-in Census service ID (letters, digits, `_`) |
| `PS2_SYNC_DISCORD_CLIENT_ID` | the ELME Discord application (17–20 digits): online sync sign-in and default Rich Presence application |

Without them the app uses `example`, and online sync and Rich Presence need a
Discord application ID of your own, see [Getting Started](Getting-Started#census-service-id) and
[Discord Rich Presence](Discord-Rich-Presence).

## Structure

| Part | Content |
|---|---|
| `crates/ps2-tracker-core` | no GUI: Census client (rate limit, retry), ESS client (reconnect, backoff), event model, session logic, tracker, achievements, voice (facts, triggers, selection, queue), pack loader (open/Recursion), crosshair library, SQLite |
| `src-tauri` | Tauri app: commands, audio (rodio), windows, tray, hotkeys, OBS endpoint, window focus (XWayland) |
| `src/` | Svelte 5 user interface (main UI, overlay, crosshair); texts in `src/lib/i18n/en.ts` |

Test data: real ESS events (public game data, pseudonymised) in `tests/fixtures/`;
audio and Recursion fixtures are generated by the project
(`tools/gen_test_ogg.py`).

The screenshots in this wiki show the browser preview with synthetic sample
data: `pnpm build` and a headless browser on `vite preview` (parameters such as
`?page=analytics&theme=light` are in `src/lib/demo.ts`).
